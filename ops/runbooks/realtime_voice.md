# Anchor realtime voice

## Contain

Use the authenticated operations control plane to create the configured
ANCHOR_REALTIME_KILL_FILE on every active gateway worker. The supervisor checks
it every 5 ms; actual reaction includes event-loop scheduling and send deadlines.
New admissions close with 1013. Active sessions cancel generation and synthesis.
The local offline test creates this file in a temporary directory.

## Preserve context

Inspect realtime_handoffs through the authenticated human-agent application.
Authorize by tenant and ticket before returning any payload. Handoffs contain
redacted transcript, acknowledged reply prefix, evidence references, reason,
pending-action status, and approval requirement. No voice event executes tools.
Do not log credentials, raw audio, attachment spans, or unredacted transcript.

## Diagnose

Correlate trace_id, epoch, stage timestamps, queue_depth, frame_gap, and send_ms.
A growing output queue with normal input points to a slow consumer. A sequence
gap terminates the utterance. Long STT, generation, or TTS intervals identify
adapter stalls. Compare loop scheduling delay before adding provider capacity.

## Recover and release

Fix the cause, rerun accumulated tests and injection regression, and collect
real shared-broker, authorization, load, playback, and judge evidence. Remove
the kill file through the same audited control plane. Fixture passes alone
must never authorize release. Reconnection always requires a new credential.
